# Polkupyörä tracker – Map frontend (Vite + React + JavaScript + Leaflet)

- Koodi on JavaScriptiä

## Käyttö

1) Pura zip ja avaa kansio VS Codessa
2) Asenna:
   - `npm install`
3) Käynnistä:
   - `npm run dev`
4) Avaa Viten URL

Jos kansiopolku on epäselvä klikkaa frontend_tmp hiiren oikealla ja valitse “Open in Integrated Terminal”
jolloin npm install ja npm run dev

Ctrl + C aja palvelin alas

## Missä muokataan?

- Karttasivu: `src/features/map/MapPage.jsx`
- Kontrolit/valikko: `src/features/map/ui/MapControls.jsx`
- Mock-data: `src/features/map/mockThefts.js`
- Tyylit: `src/styles.css`
